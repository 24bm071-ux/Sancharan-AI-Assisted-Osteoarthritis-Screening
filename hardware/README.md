# Hardware

This directory contains the hardware architecture, sensor information, pin connections and prototype hardware documentation.

## Sensors

- Dual MPU-9250/MPU-6500-compatible IMUs
- INMP441 digital I2S microphone
- Surface EMG sensing module
- HLK-LD2402 radar module

## Controller

ESP32-S3 is used as the primary embedded controller for the multimodal prototype.

The radar prototype was separately tested using an ESP32-C3 SuperMini.
