# Data

This directory documents the data generated and planned for the Sancharan multimodal osteoarthritis screening system.

The system collects complementary data from multiple sensing modalities to study movement and functional patterns associated with osteoarthritis.

## Data Modalities

| Modality | Sensor | Primary Data |
|---|---|---|
| IMU | 2 × MPU-9250/6500 | 3-axis acceleration and 3-axis angular velocity |
| Acoustic | INMP441 | Digital acoustic samples |
| EMG | EMG sensor | Muscle electrical activity |
| Radar | HLK-LD2402 | Distance and radial movement information |

---

## 1. IMU Data

Two IMUs are used to capture the movement of the thigh and shank.

### Recorded signals

- Accelerometer X, Y, Z
- Gyroscope X, Y, Z
- Timestamp
- Sensor identification

### Potential features

The IMU signals can later be processed to obtain:

- Knee movement
- Joint angle
- Range of motion
- Angular velocity
- Gait characteristics
- Movement symmetry
- Temporal variability

---

## 2. Acoustic Data

The INMP441 digital I2S microphone is used to capture acoustic information during movement.

### Recorded data

- Digital acoustic samples
- Timestamp

### Planned processing

The acoustic signal can be analyzed using:

- Filtering
- Amplitude analysis
- Time-domain features
- Frequency-domain features
- Spectral analysis

The current implementation is a proof-of-concept acoustic acquisition system. It is not being presented as a clinically validated vibroarthrography system.

---

## 3. EMG Data

EMG measures electrical activity generated by muscles during movement.

### Potential features

- RMS amplitude
- Mean absolute value
- Signal envelope
- Activation timing
- Frequency-domain characteristics
- Muscle activation patterns

EMG acquisition must use an appropriate biomedical signal-conditioning and electrode interface.

---

## 4. Radar Data

The HLK-LD2402 radar provides contactless movement information.

### Recorded parameters

- Detection status
- Distance
- Filtered distance
- Radial velocity
- Movement direction
- Detection duration

Radar is intended as a complementary movement-sensing modality and does not replace detailed joint kinematic measurements obtained from IMUs.
